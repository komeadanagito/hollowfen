## 1. 目标与定位

做出 Hollowfen 的**第一关 = 引导教学关卡**的完整设计蓝图。

教学关唯一职责：在安全、递进的环境里，教会玩家本作的核心机制，并把高潮放在**角色切换**上——本作的身份机制。

**核心决策（已确认）**：

| 维度 | 决策 |
|------|------|
| 实现时机 | 纸面设计，暂不写代码 |
| 角色解锁 | 开局只有 Knight；**中途解锁 Archer**（解锁本身是一个高光节点） |
| 教学方式 | **明确教程提示为主**（触发式按键提示面板，做完一次即淡出；后续可做「重复游玩时不再显示」） |
| 风险程度 | **低风险**：敌人/陷阱会扣血，死后就近重生满血（复用 Phase 0 重生），整体宽松 |

**教学设计原则**：一次只教一件事 → 安全练习 → 低风险小测 → 应用。每个机制一个「段落」。

**叙事框架**：玩家以 Knight 的身份在沼泽边缘苏醒，目标是抵达沼泽深处的「门」。Archer 是中途唤醒的同伴。气质延续黑暗沼泽，但教学段落叠加明确的按键提示。

## 2. 整体教学弧线（脊柱）

| 段落 | 教什么 | 怎么教（地形 + 提示） | 风险 |
|------|--------|--------------------|------|
| **1. 苏醒** | 移动 + 跳跃 | 封闭小空间起步，提示「← → 移动」；前方一道矮沟/台阶，提示「跳跃」。无敌人，纯建立操作信心。土狼时间/跳跃缓冲让它很宽容。 | 无 |
| **2. 第一滴血** | 近战攻击 + 接触伤害 | 一个 Phase 0 巡逻敌人挡路，提示「攻击」。Knight 砍死它。玩家第一次尝到「碰到敌人会掉血」。此处放一个重生点。 | 低（可死） |
| **★ 解锁 Archer** | 「一个角色不是万能的」 | 走廊被 Door 挡住，开关在门上方高处——Knight **跳不到也砍不到**（卡住）。门前有沉睡的 Archer → 触碰唤醒，解锁切换。 | 无 |
| **3. 另一只手** | 切换 + 射箭 | 提示「切换角色」→ 切到 Archer → 提示「射箭」→ 射中高处开关 → 门开。这是「啊哈」时刻：切换 = 通路。（复用 Phase 0 开关-门谜题，放在教学高潮位置。） | 无 |
| **4. 二合一** | 流畅来回切换 | 门后组合房：一个稍硬的敌人 + 又一个高处开关。**不再给提示**（毕业测试），证明切换循环成立。 | 低 |
| **5. 门** | 关卡终点 | 抵达沼泽深处的蓝光门，教学关结束。完整游戏里这里接存档点/第一个 Hub。 | — |

**可选教学点（残血切换）**：HP 是**每角色独立**的。可在段落 4 把 Knight 的血量设计成此处会变低，引导玩家「切到满血 Archer」，自然体会切换也是一种生存策略。默认保留为可选，实现时再定。

**重生/难度**：敌人只蹭少量血；死后在最近重生点满血复活（复用 Phase 0 重生）。战斗段落附近都放重生点。

## 3. 画面与显示（全局设置）

| 项 | 值 | 说明 |
|----|----|----|
| 视口分辨率 | **1920×1080**（16:9） | 由当前默认 1152×648 提高到主流 1080p |
| 拉伸模式 | `canvas_items` + aspect `keep` | 不同窗口大小等比缩放，不变形 |
| 基础网格单位（tile） | **64 px** | 所有地形/障碍方块按 64px 网格摆放，后续换图好对齐 |
| Knight 尺寸 | **96×144 px**（约 1.5×2.25 tile） | 比当前 28×40 大很多，厚重感 |
| Archer 尺寸 | **80×140 px** | 略瘦高，脆弱感 |
| 敌人尺寸 | **80×80 px** | — |
| 相机 zoom | 1.0（暂定） | 角色变大后视野够，先不缩放 |

> **手感校准（实现时任务）**：角色与世界尺度变大后，移动速度、跳跃初速度/高度、重力、攻击判定范围都要按比例重调。纸面先记下，作为实现阶段的独立「手感校准」任务。

## 4. 占位与物料注释规范（方便后续替换美术）

阶段性占位仍是**色块方块**，逻辑与美术解耦。每个占位物体带**两层标注**，换美术时一眼定位：

1. **命名规范**：`PH_<类别>_<用途>`，如 `PH_Terrain_Ground`、`PH_Obstacle_Crate`、`PH_Switch_A`、`PH_Door_Main`。`PH_` = Placeholder。
2. **Inspector 注释**（节点的 `editor_description` 字段，悬停可见），统一格式：
   ```
   [物料] 类别=地形 | 占位=灰方块 192×64 | 替换=沼泽石台贴图 | 备注=可站立
   ```
3. 本文档第 7 节附**物料清单表**（占位 → 计划最终资源），作为美术 TODO 总账。

| 占位 | 颜色 | 代表 |

## 5. 空间布局（从左到右的横版走廊，相机跟随）

```
段1 苏醒              段2 第一滴血        解锁         段3 另一只手           段4 二合一              段5
┌─────────┐         ┌──────────┐                  ┌──────────────┐     ┌──────────────┐      ┌────┐
│         │         │          │                  │   ▣ 开关(高)  │     │  ▣开关(高)    │      │ ▤  │
│  K→     │   _∏_   │   K  e→  │  [门] ▣Archer    │ K/A    [门]   │     │ K  E2  A     │      │终点│
│███████ ∏ ███████████████████████  ███  █████████████  ████████████████████████████████████████████│
└─ ←移动  └跳跃 ───┘ └攻击/重生点┘   └Knight卡住└切换/射箭┘      └毕业(无提示)┘       └出口┘
   提示                                  ↑唤醒Archer
```

图例：`K`=Knight 起点 `e`=弱巡逻敌 `E2`=稍硬敌人 `▣`=开关（高处够不到） `[门]`=Door `∏`=矮台阶/沟 `▤`=终点门 `█`=地形。

- **段1 苏醒**：平地起步（`←→移动` 提示）；一道矮沟或台阶（`跳跃` 提示）。无敌人。
- **段2 第一滴血**：小竞技场，1 个 Phase 0 巡逻敌（`攻击` 提示），旁边一个重生点。
- **解锁**：走廊被 Door 挡住，开关在门**上方高处**——Knight 跳不到也砍不到（卡住）。门前有沉睡的 Archer → 触碰唤醒，解锁切换。
- **段3 另一只手**：`切换角色` 提示 → 切 Archer → `射箭` 提示 → 射中高处开关 → 门开。**啊哈时刻**。
- **段4 二合一**：门后组合房——稍硬的敌人 `E2` + 又一个高处开关。**不给提示**，逼玩家自己来回切。（可选：Knight 在此会残血，引导切到满血 Archer。）
- **段5 门**：抵达终点蓝光门，关卡结束。

## 6. 需要的新部件（纸面记，实现时落地）

本关复用大量 Phase 0 资产（CharacterBase、Knight、Archer、PartyManager、巡逻敌人、Switch、Door、Health、Hitbox/Hurtbox、重生）。新增/改动如下：

### 6.1 教程提示系统
- **`PromptZone`（Area2D）**：导出 `prompt_text: String` 和 `prompt_id: String`。激活角色进入 → 通过 `TutorialLayer`（CanvasLayer）显示一行提示面板。
- **消失条件**：绑定到对应机制完成一次（跳一次/砍一次/切一次/射一次）后淡出，且记录 `prompt_id` **不再重复**显示。
- **`TutorialLayer`（CanvasLayer）**：持有提示面板 Label，提供 `show_prompt(id, text)` / `dismiss(id)`。

### 6.2 角色解锁
- **`ArcherPickup`（Area2D）**：Knight 触碰 → 调 `PartyManager.unlock(archer)`。
- **PartyManager 改动**：角色支持「锁定/解锁」标记。开局 Archer 在队列里但锁定，`switch_to_next()` 跳过锁定角色；解锁后方可切入。解锁时发 `character_unlocked` 信号（供提示/特效）。

### 6.3 关卡出口
- **`LevelExit`（Area2D）**：激活角色进入 → 发出关卡完成信号（阶段 0/1 先只打印或淡出；完整游戏接场景切换/存档）。

### 6.4 显示设置
- `project.godot` 增加 `[display]` 段：viewport 1920×1080，stretch `canvas_items` / aspect `keep`。

## 8. 范围边界

### ✅ In Scope（本关设计）
- 5 段线性教学走廊 + 中途解锁 Archer + 切换高潮谜题
- 明确教程提示系统（触发式、做完淡出、不重复）
- 低风险难度 + 就近重生
- 1920×1080 显示、64px 网格、放大角色、占位方块 + 物料注释规范
- 复用 Phase 0 全部战斗/角色/谜题资产

### ❌ Out of Scope（留给后续）
- 真实美术/音效/视差背景/剧情演出（阶段 5）
- 存档、场景切换、地图、与 Hub 的连接（阶段 1/4）
- 新敌人种类/复杂 AI/Boss（阶段 2）
- 多机关组合解谜库（阶段 3）
- 第 3 个及以后的角色

## 9. 完成判定标准

玩家从沼泽边缘苏醒 → 学会移动/跳跃 → 砍掉第一个敌人 → 在门前卡住 → 唤醒 Archer → 切换并射中高处开关开门 → 在组合房自主来回切换 → 抵达终点门。全程提示清晰、低挫败，且让玩家**真切感到「切角色」是解决问题的关键**。
